# 객체 인식 기반 미로 탈출 제어 시스템

## 문제

- 학습한 객체가 테스트마다 일관되게 인식되지 않았다
- 인식 결과가 LED 경로 표시 로직에 안정적으로 연결되지 않았다
- 2인 팀이었으나 팀원 개인 사정으로 **실질 1인 체제**였고 준비 시간이 제한돼 있었다

## 검토와 판단

통합된 상태로 디버깅하면 문제가 인식 단계인지 경로 로직 단계인지 구분하는 데 시간이
과도하다고 판단했다. **두 기능을 분리해 각각의 정상 동작 기준을 먼저 세웠다.**

반복 테스트로 인식이 잘 되는 경우와 오인식이 나는 경우를 구분했다. 오인식 패턴이 촬영
위치·각도 같은 환경 조건과 직결된다고 보고, **알고리즘을 크게 바꾸기보다 학습 이미지
조건과 촬영 환경을 정리하는 쪽**을 우선했다.

## 한 일

- 인식 결과에 따라 경로가 달라지는 분기 로직을 설계하고 LED 점등·점멸 순서와 연결
- 아두이노 제어와 전체 흐름을 통합 테스트하며, 입력이 흔들려도 경로 표시가 깨지지 않는지
  반복 확인

## 결과

- 초기 대비 인식 흔들림과 경로 어긋남이 크게 줄어, 인식 결과가 들어오면 경로가 끝까지
  일관되게 표현되는 수준까지 개선
- 대회 당일 요구된 기능을 안정적으로 시연하고 **AI-EYE부문 1등**

## 내 기여

객체 인식 구현, 아두이노 제어, 미로 탈출 판단 로직 설계, 통합 테스트 전 과정을 혼자
수행했다.

## 다시 한다면

인식·판단·출력을 분리해 정상 동작 기준을 세우는 접근은 이후 작업에서도 계속 쓰고 있다.
이때는 감으로 했고, 지금은 그게 방법이라는 걸 안다.
